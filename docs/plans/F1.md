## Layout

```
Countdown.xcodeproj       hand-written; Xcode's folder-synchronized groups, so a new file needs no project edit
App/                      host app (SwiftUI, iOS + macOS)
Widgets/                  widget extension: provider, intent, widget bundle
Shared/                   StyleView, the one renderer, compiled into both targets
CountdownCore/            unchanged location; gains the store and the display model
```

**The project file is written by hand, not generated.** A generator such as XcodeGen is a third-party tool (`D14`). `xcodebuild` in CI is what proves the hand-written project works (`RR9`).
